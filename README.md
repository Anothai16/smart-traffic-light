# ระบบควบคุมสัญญาณไฟจราจร (Smart Traffic Light System)

## ภาพรวมของโปรเจกต์
โปรเจกต์นี้คือระบบควบคุมสัญญาณไฟจราจรแบบอัจฉริยะที่แบ่งออกเป็น 2 ส่วนหลัก:
1.  **ส่วนควบคุม (Backend):** ทำงานบน Raspberry Pi เพื่อควบคุมไฟ LED ที่เชื่อมต่อผ่านขา GPIO
2.  **แดชบอร์ด (Frontend):** เว็บแอปพลิเคชันที่สร้างด้วย React เพื่อใช้ในการแสดงผลสถานะของสัญญาณไฟ และดูวิดีโอจากกล้องตามจุดต่างๆ

ระบบนี้ทำงานร่วมกันผ่านฐานข้อมูล SQL Server โดยส่วนควบคุมจะตรวจสอบโหมดการทำงานจากฐานข้อมูล และผู้ใช้สามารถดูข้อมูลสถานะต่างๆ ได้ผ่านแดชบอร์ด

---

## คุณสมบัติหลัก
* **ส่วนควบคุม:**
    * **โหมดอัตโนมัติ (Auto Mode):** ทำงานตามวงจรสัญญาณไฟจราจรมาตรฐาน 4 ทิศ (เหนือ, ใต้, ออก, ตก)
    * **โหมดฉุกเฉิน (Caution & Stop):** สามารถเปลี่ยนเป็นโหมดไฟกะพริบ (เหลือง/แดง) ได้ตามคำสั่งจากฐานข้อมูล
    * **การตั้งค่าที่ยืดหยุ่น:** สามารถแก้ไขค่าเวลาและข้อมูลฐานข้อมูลได้ผ่านไฟล์ \`config.yaml\`
* **แดชบอร์ด:**
    * แสดงสถานะสัญญาณไฟแบบเรียลไทม์
    * แสดงภาพรวมของทางแยกพร้อมจุดติดตั้งกล้องวงจรปิด
    * **Camera View:** เมื่อคลิกที่ไอคอนกล้อง จะแสดงวิดีโอสตรีมสดจากกล้องที่ติดตั้งไว้ในแต่ละทิศทาง

---

## สถาปัตยกรรมของระบบ
ระบบทั้งหมดทำงานร่วมกันดังนี้:

**Raspberry Pi (Backend)** ↔ **SQL Server Database** ↔ **Dashboard (Frontend)**

* **ส่วนควบคุมบน Raspberry Pi** ดึงข้อมูลโหมดการทำงานจากตารางในฐานข้อมูลเป็นระยะๆ เพื่อกำหนดสถานะของสัญญาณไฟ
* **แดชบอร์ด (Frontend)** ดึงข้อมูลจากฐานข้อมูลเพื่อแสดงสถานะของสัญญาณไฟ และเชื่อมต่อกับเซิร์ฟเวอร์วิดีโอเพื่อแสดงฟีดกล้อง

---

## ข้อกำหนดเบื้องต้น (Prerequisites)

### ฮาร์ดแวร์
* Raspberry Pi
* ไฟ LED สีเขียว, เหลือง, แดง รวม 12 ดวง
* ตัวต้านทาน 220 โอห์ม 12 ตัว
* บอร์ด Breadboard
* สายไฟจัมเปอร์
* อุปกรณ์กล้องและเซิร์ฟเวอร์วิดีโอ (สำหรับฟังก์ชันแดชบอร์ด)

### ซอฟต์แวร์และไลบรารี
* Python 3 และ Node.js
* ฐานข้อมูล SQL Server
* ไลบรารี Python: \`pyodbc\`, \`PyYAML\`, \`RPi.GPIO\` (เฉพาะสำหรับ Pi)
* ไลบรารี Node.js: \`react\`, \`antd\`, \`classnames\`

---

## การเชื่อมต่อฮาร์ดแวร์
เชื่อมต่อขาของไฟ LED เข้ากับขา GPIO ของ Raspberry Pi ตามแผนผังด้านล่างนี้ โดยใช้ตัวต้านทานขนาด 220 โอห์ม สำหรับ LED แต่ละดวงเพื่อป้องกันกระแสไฟเกิน



### การกำหนดขา GPIO (BCM)
* **ทิศเหนือ:** \`(เขียว: GPIO 17, เหลือง: 18, แดง: 27)\`
* **ทิศตะวันออก:** \`(เขียว: GPIO 22, เหลือง: 23, แดง: 24)\`
* **ทิศใต้:** \`(เขียว: GPIO 25, เหลือง: 5, แดง: 6)\`
* **ทิศตะวันตก:** \`(เขียว: GPIO 12, เหลือง: 13, แดง: 16)\`

## การตั้งค่าและเริ่มต้นใช้งาน

### ขั้นตอนที่ 1: ตั้งค่าส่วนควบคุม (Backend)
1.  ติดตั้งไลบรารี Python บน Raspberry Pi:
    \`\`\`sh
    pip install pyodbc
    pip install pyyaml
    pip install RPi.GPIO
    \`\`\`
2.  สร้างไฟล์ \`config.yaml\` และกำหนดค่าฐานข้อมูลของคุณ:
    \`\`\`yaml
    # Traffic Light Configuration
    traffic_light:
      green_duration: 10
      yellow_duration: 3
    
    # Database Configuration
    database:
      driver: "{ODBC Driver 17 for SQL Server}"
      server: "DESKTOP-QDN7QAS"
      name: "Smart_Traffic_Light"
      uid: "admin"
      pwd: "1234"
    \`\`\`
    (แก้ไขค่า \`server\`, \`uid\`, และ \`pwd\` ให้ตรงกับข้อมูลของคุณ)
3.  รันสคริปต์ Python ใน Terminal:
    \`\`\`sh
    python traffic_controller.py
    \`\`\`

### ขั้นตอนที่ 2: ตั้งค่าแดชบอร์ด (Frontend)
1.  ติดตั้ง Node.js และ npm บนเครื่องของคุณ
2.  ในโฟลเดอร์โปรเจกต์แดชบอร์ด ให้ติดตั้งไลบรารีที่จำเป็น:
    \`\`\`sh
    npm install
    \`\`\`
3.  รันแดชบอร์ดในโหมดพัฒนา:
    \`\`\`sh
    npm start
    \`\`\`
    (แดชบอร์ดจะเปิดขึ้นในเว็บเบราว์เซอร์ของคุณที่ \`http://localhost:3000\` โดยค่าเริ่มต้น)

## การแก้ไขปัญหา (Troubleshooting)

**ปัญหา:** ได้รับข้อความแจ้งเตือน \`Import "RPi.GPIO" could not be resolved from source\` บน VS Code

**สาเหตุ:** ไลบรารี \`RPi.GPIO\` เป็นไลบรารีเฉพาะสำหรับ Raspberry Pi และไม่สามารถติดตั้งหรือใช้งานบนคอมพิวเตอร์ทั่วไปได้

**แนวทางแก้ไข:**
* ข้อความนี้เป็นเพียงการแจ้งเตือนจากโปรแกรมแก้ไขโค้ด (เช่น Pylance) และไม่ได้เป็นข้อผิดพลาดของโค้ด
* โค้ดจะทำงานได้อย่างถูกต้องเมื่อถูกนำไปรันบน Raspberry Pi ที่มีไลบรารีนี้ติดตั้งอยู่แล้ว
